# Arena Insana Pro ⚔️

Inspirado en la estética e interfaz de Arena de Poderes.
Hero shooter 2D top-down con multijugador en tiempo real de hasta 10 jugadores.

## Despliegue en Render:
1. Descomprime este `.zip` en la raíz de tu proyecto.
2. Sube todos los archivos a tu repositorio de GitHub.
3. Ve a [Render.com](https://render.com) -> **New +** -> **Web Service**.
4. Conecta tu repositorio.
5. Configuración:
   - **Environment**: `Node`
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
