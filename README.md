# Arena Insana
Proyecto Node.js + Express + Socket.IO.

## Publicar en Render
- New > Web Service
- Conecta el repositorio GitHub
- Runtime: Node
- Build Command: `npm install`
- Start Command: `npm start`
- Root Directory: vacío
- Instance: Free para pruebas

El servidor usa `process.env.PORT` y sirve el cliente desde `public/`.

## Incluye
- Salas privadas por código, hasta 10 jugadores.
- Seis mapas seleccionables.
- Seis personajes seleccionables.
- Movimiento, ataque, habilidad con enfriamiento, vida y puntuación.
- Controles teclado y controles táctiles básicos.

## Alcance
Es una versión jugable inicial para pruebas. No incluye todavía persistencia, cuentas, matchmaking global, sistema competitivo, sprites animados originales ni protección anti-trampas de producción.
