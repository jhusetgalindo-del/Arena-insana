# Arena Insana ⚔️

Juego multijugador 2D Top-Down Hero Shooter de hasta 10 jugadores con soporte táctil para móviles y PC.

## Despliegue en Render:

1. Descomprime este archivo `.zip` en la raíz de tu proyecto.
2. Sube todos los archivos a tu repositorio de GitHub.
3. Ve a [Render.com](https://render.com) -> **New +** -> **Web Service**.
4. Conecta tu repositorio de GitHub.
5. Configuración del servicio:
   - **Environment**: `Node`
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
6. Haz clic en **Create Web Service**.
